# PERSEPOLIS Mini App — static starter

Front-end demo in Persian and English, designed for mobile.

## Upload
Upload `index.html`, `style.css`, `app.js`, and `README.md` to the root of your existing GitHub repository. Upload `assets/persepolis.svg` into a folder named `assets`.

## Important
This is a front-end demo only. Mining numbers are simulated in the browser. The wallet button does not connect to TON, and no PER is transferred or paid out.

A real launch requires TON Connect with a valid manifest, the real PER Jetton master contract address, server-side reward accounting and anti-abuse controls, and a funded payout wallet/treasury. Never put bot tokens, private keys, or seed phrases in this repository.
